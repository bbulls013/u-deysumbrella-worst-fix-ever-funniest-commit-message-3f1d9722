# Worst Fix Ever: Funniest Commit Message

A deterministic program that writes the funniest commit message for the worst
fix ever. The fix removes the bug the only way it knows how — by deleting the
feature, the tests, and the will to investigate — and then ships it anyway.
Ninety-three characters of honest engineering.

## Run

```sh
python3 main.py
```

Writes the message to `/output/entry.txt` (override with `MAKEFUN_OUTPUT`).
Two runs produce byte-identical output: 93 characters, inside the gate of
1–100 characters.
